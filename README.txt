FACULTY APPOINTMENT REQUEST SYSTEM
Technology: PHP + MySQL + HTML/CSS
Server: XAMPP

INSTALLATION:
1. Copy the folder "faculty_appointment_system" into C:/xampp/htdocs/
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin
4. Create/import database.sql.
5. Open http://localhost/faculty_appointment_system/
